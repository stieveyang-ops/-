## 调用链 1：正常样例 —— 咖啡酸逆合成（主链）

```powershell
$env:PYTHONUTF8 = "1"   # 中文路径 UTF-8 防护（launch_gui.cmd / launch_gui.ps1 已内置）

& "C:\Users\18706\miniconda3\envs\aizynth-portable\python.exe" -s `
  "prospective_difficulty_tool\prospective_score.py" `
  --project-dir "frozen_project" `
  --smiles "O=C(O)/C=C/c1ccc(O)c(O)c1" `
  --target-id "evidence_caffeic_20261013" `
  --output-dir "prospective_runs\evidence_caffeic_20261013" `
  --iteration-limit 100 --time-limit 120 --max-transforms 6 `
  --max-routes 10 --min-routes 3
```

**链式调用路径**（该命令内部依次调用）：

```
prospective_score.py
  ├─ frozen_project/src/aiz_rd/chemistry.py          → canonicalize_molecule_smiles（RDKit 解析/规范化）
  ├─ AiZynthFinder 4.4.1 (MCTS)                      → 加载 uspto_model.onnx / uspto_templates.csv.gz
  │                                                    / uspto_ringbreaker_model.onnx / uspto_filter_model.onnx
  │                                                    / zinc_stock.hdf5（35,205,265 个库存化合物）
  ├─ frozen_project 冻结难度模型                      → 三特征评分 d_feas / d_prec / d_sc + 前例检索
  │                                                    (cosine, tau=0.8, N0=10, top_k=100)
  ├─ frozen_project/.conda-rxnfp/python.exe           → rxnfp 反应指纹（256 维）
  └─ 输出 → prospective_manifest.json / scored_routes.json / scored_routes.csv /
            scored_reactions.csv(.parquet) / reaction_diagrams/ / prospective_dashboard.html
```

结果：`{"status": "PASS", "routes": 10, "reaction_rows": 10, "manifest_sha256": "A4CC720C..."}`

  --iteration-limit 100 --time-limit 120 --max-transforms 6 --max-routes 10 --min-routes 3

## 调用链 4：失败样例

```powershell
# 失败 1：无效 SMILES（环无法闭合）
& $py -s ... --smiles "C1CCCC" --target-id "evidence_badsmiles_20261013" ...
# → exit=1，ChemistryStandardizationError: RDKit parse/sanitize failed ... 'C1CCCC'

# 失败 2：非法参数组合
& $py -s ... --smiles "CCO" --target-id "evidence_badparams_20261013" ... --max-routes 2 --min-routes 5
# → exit=2，BLOCKED：min-routes/max-routes must satisfy 0 <= min_routes <= max_routes
```
