## 分析一个分子

1. 在 Target molecule SMILES 中输入目标分子的 SMILES，例如 `CCOC(=O)c1ccccc1`。
2. 填写 Target ID，例如 `ethyl_benzoate_001`。


## 双击启动后"窗口一闪而过 / 界面打不开"怎么办（2026-10-14 修复）

### 现象

双击 `launch_gui.cmd`（或 `启动_可运行作品.cmd`）后，黑色命令行窗口一闪就消失，**图形界面没有出现**。

### 原因（已定位）

启动脚本的第一步是**环境校验**（`validate_environment.py`），校验里含一项"反应指纹独立运行时冒烟测试"：它会创建一个临时目录，让 `frozen_project\.conda-rxnfp\python.exe`（Python 3.8）写一个 `output.npy` 再读取校验形状。

本机实测发现：**该 Python 3.8 解释器只能写交付包内部的目录**，写系统 `TEMP`、`C:\Windows\Temp`、`%USERPROFILE%\Documents`、`%LOCALAPPDATA%` 一律被拒绝（`PermissionError: [Errno 13]`），而主环境 Python 3.10 写这些位置都正常。原因属于系统/安全软件对这一个解释器进程的写入限制，与作品内容无关。

由于原校验把临时目录建在**系统 TEMP** 上，冒烟测试必然失败 → 校验返回非 0 → `launch_gui.ps1` 抛错退出 → 窗口一闪而过。这与"浏览器打不开"是同一个根因：界面根本没来得及启动。

### 修复（已于 2026-10-14 完成并实测）

1. **`validate_environment.py`**：反应指纹冒烟测试的临时目录改为**交付包内**的 `_runtime_check_tmp\`（用后自动删除；若无法创建则回退系统 TEMP）。校验语义完全不变，只是换了临时目录位置。
2. **`launch_gui.cmd`**：启动失败时**窗口保持打开**并打印退出码与三条常见原因（校验未通过 / 被 Windows 安全警告拦截 / 未找到 Python 环境），不再"一闪而过"。修复前的原文件备份为 `local_deployment\pre_20261014_fix_launch_gui.cmd`。
3. 修复已同步到 `第二项\` 副本与 `C:\Users\18706\OneDrive\Desktop\Aizynth_Work\AIZynthFinder_RD_Portable_2026-10-13\`（桌面快捷方式指向的副本）。

## 首次运行出现"打开文件 - 安全警告：无法验证发布者"怎么办（2026-10-14 补充）

**这不是程序故障，也不是病毒。** 这是 Windows 的"附件管理器"（Attachment Manager）对**带有"网络来源"标记**的脚本文件（`.cmd` / `.bat` / `.ps1`）的标准提示：任何没有数字签名的脚本，Windows 都会显示"发行商：未知发布者"。本作品是学生作品，未购买代码签名证书，因此出现该提示属正常现象。

### 为什么会带上"网络来源"标记

Windows 会为来自互联网、网盘/云同步（如 OneDrive）、即时通讯或压缩包下载的文件写入一个备用数据流 `Zone.Identifier`。本交付包位于 `OneDrive\Desktop\黑客松\待提交作品\`，是新建立的目录，OneDrive 上传并回迁（按需下载）时可能给其中的脚本重新打上该标记，因此**第一次双击 `launch_gui.cmd` 时可能弹出提示**。本机核查结果：文件内容与哈希均正确，无任何异常属性；出现提示只与来源标记有关。

### 三种解决办法（任选其一）

**方法一（推荐，一次性彻底解决）**：在交付包根目录双击 `解除文件锁定.cmd`（本包新增），它会递归清除本目录及子目录下所有文件的来源标记，之后双击任何启动脚本都不再提示。命令行等价写法：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\解除文件锁定.ps1
```

**方法二（只处理单个文件）**：右键该文件 → 属性 → 常规选项卡底部勾选"解除锁定"→ 确定。

**方法三（直接点过去）**：在提示框点击"运行(R)"即可正常启动。该提示只对**每一个首次运行的脚本**出现一次，之后不再询问。

### 说明与验证

- 清除"网络来源"标记只删除 `Zone.Identifier` 备用数据流，**不修改文件内容**，因此不影响 `package_completeness_report.json` 与 `package_reference_sha256.csv` 中的 25 项 SHA256 校验结果（已实测：解锁前后文件哈希完全一致）。
- 若希望完全避免此类提示，可把整个交付包复制到非云同步目录（例如 `D:\aizynth_work\`）后再运行。
- 现场核查记录（2026-10-14）：交付包内带来源标记的文件共 36 个（含 ONNX 模型、ZINC 相关文件与 `.conda-rxnfp` 中若干第三方包文件），已全部解锁，处理后为 0 个；`launch_gui.cmd` 等启动脚本本身的两个副本（根目录与 `第二项\`）哈希一致、属性正常。
